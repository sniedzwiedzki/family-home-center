# Run: hour view of one expanded day

Date: 2026-10-18
Spec: `.ai/specs/implemented/2026-10-18-hour-view.md`

## Steps
1. Pure helpers in `dayHours.ts` (spans, hour range, day-over rule, lane placement) and `useClock` (one-minute clock).
2. `HourBody` renders the grid and now-line; `DayRow` takes an `expansion` prop and its date becomes a toggle button; `CalendarView` owns the single expanded day (automatic default plus a user choice tied to the day it was made) and the home target; `ColumnHeaders` got the home button.
3. Tests for all of it; CalendarView tests fake `Date` so the hour view does not depend on when they run.

## Decisions
- The hour grid is a second grid row inside the same `.day-row`, so the today-pin logic keeps measuring one element.
- Timed continuation days of multi-day events go to the compact row (so they never stretch the range to midnight).

## Verification
- `npm run lint`, `npm run build`, `npm test` (100% coverage), `npm run test:integration` locally at 1600 x 2400; screenshots checked.
